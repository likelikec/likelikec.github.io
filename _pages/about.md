我的方向是 **GUI Agent 与智能软件测试**：让大模型智能体在真实设备上（Android 手机、X11 桌面、浏览器）完成完整的操作任务，同时把这些过程做成**可评测、可复盘、可被人接管**的系统，而不只是一次性的演示脚本。

<h3>研究方向</h3>

- **GUI Agent 架构与能力边界** — 在统一的 Android 交互环境和统一底座下，对比 reactive 单智能体、explore-then-deploy 等设计模式，分析它们在任务复杂度、状态扰动、页面复杂度下的边界表现，并对失败做可解释归因。
- **人机协同的移动端自动化** — 把自主规划、动作执行、结果反思与人工介入放在同一条执行链路里，比较无介入、高层介入、低层介入、混合介入四种模式的成功率与成本。
- **跨平台 GUI 测试执行** — Web（Playwright）、桌面（X11 + 视觉定位）、Android（ADB）三条执行链路，产出人能读的报告：HTML + Excel + 截图轨迹 + GIF。
- **科研情报自动化** — 用 GitHub Actions 把论文抓取、打分、精读与证据核验串成零服务器流水线。

<h3>最近在做</h3>

- 整理 GUI Agent 各设计模式的横向对比实验与失败归因。
- 推进移动端人机协同框架的人机介入策略与轨迹自纠正。

I am **【Your Name】**, a 【graduate student / research assistant】 at **Nanjing University**, working on **GUI agents and intelligent software testing**.

My work sits on one question: can an LLM-driven agent actually finish a real task on a real device — an Android phone, an X11 desktop, a browser — and can we **evaluate, replay, and intervene** in what it does, instead of shipping one-off demo scripts?

**Research interests**

- **Cross-platform GUI test execution** — Playwright for web, vision-based grounding plus native input on X11, ADB on Android, all producing human-readable reports (HTML, Excel, screenshot traces, GIFs).
